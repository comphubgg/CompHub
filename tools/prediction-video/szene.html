It estimates the points needed.
Step 1 · History

It starts with past editions.

The points at exactly the qualifying rank in the last editions of the same cup — up to 3.

Averaged, plus a small 5-point safety margin.

No earlier edition? It uses similar cups instead — same mode, team size and match count.

Example values
Step 2 · Learning

It learns from its own mistakes.

After every cup it stores prediction vs. real result.

The average error of the last 6 cups of the same type is applied as a correction.

Prediction vs. real result
Example values
Step 3 · Live

It updates during the cup.

Once about 60 % of the games are played (game 5 of 8),

it projects the current qualifying line to the full cup once, and locks it.

If the old prediction was already within 3 %, it stays as it is.
